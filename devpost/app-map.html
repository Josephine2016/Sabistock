SabiStock App Map

A compact guide to the restock dashboard, its photo flow, and where to start when changing it.

What the app does

SabiStock helps a small phone or computer-accessory shop see what needs restocking. It groups items by quantity, keeps the lowest stock first, and saves the owner’s inventory in this browser.

The app has no backend or online libraries. Inventory stays in the same browser and device; use the local server for a reliable saved-inventory demo.

Reference route through the code

This is a route for revisiting the code, not a claim that every reader has completed it.

  1. Photo selection and preview

    In index.html, search for photoInput.addEventListener("change". It passes the chosen file into the photo-preparation step and shows the compressed preview.

  2. Resize and compress

    Search for async function compressPhoto. The canvas preserves the image proportions within 300 × 300 pixels and tries JPEG quality settings until the image data is at most 20 KB.

  3. Save and display

    Search for form.addEventListener("submit" and function saveInventory. The new item's photo is set from pendingPhoto, serialized under sabistock_items, and then displayed by render and itemCard.

To change this, start here

  • Stock thresholds and bucket order: function render in index.html.
  • Card details and Sold/Add actions: function itemCard in index.html.
  • Name and quantity checks: the form submit handler in index.html.
  • Photo size, compression, and preview: compressPhoto and the photo input change handler in index.html.

A practice to reuse

Turn a vague quality goal into an observable check. Here, the photo requirement became a 300 × 300 maximum and a JPEG image-data limit of 20 KB; the browser check confirmed a 300 × 150 thumbnail at 2,011 bytes that remained after reload. In another project, connect a measurable requirement to the output you can inspect, then test it after the relevant action.

What evidence was checked?

The chosen photo produced a JPEG data URL; its decoded image data was measured at 2,011 bytes, the dashboard displayed the saved image after reloading, and a separate test confirmed an item without a photo used the placeholder.

Run it again

From the project root, run npx --yes serve . and open the local URL printed by the command, usually http://localhost:3000. Keep the server running. The app itself makes no external requests; internet may be needed the first time to download the local server tool.

Items persist for this browser and local address. This is not a hosted offline app, so localhost is unavailable while the local server is stopped.
